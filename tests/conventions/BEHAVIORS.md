# conventions lint — behaviour table

Written before the code, 2026-10-14. Each expected value comes from the rule the check enforces:
`.claude/rules/session-inputs.md` for C1–C7 and `.claude/rules/dashboard.md` for C8. The allowlist
rows come from `tests/conventions/allowlist.txt`'s own contract, the H rows from the Owner's ask that the
pre-commit hook run the lint on every commit, and T1 from the requirement that
the tree the lint landed on passes. An `Assumed` row is a default the source does not settle.

The lint is `python3 tests/conventions/lint.py [--root <dir>] [--allowlist <file>]`. It reads the
files under `<root>` in the scope `.claude/rules/session-inputs.md` names: `skills/*/scripts/*`,
`skills/*/hooks/*`, `tools/**` and `install.sh`. A finding prints as
`conventions: <check> <path>:<line>: <source line>`.

Every fixture is written to a scratch root. It is syntax only: names it uses are never defined,
and no command string it holds does anything.
